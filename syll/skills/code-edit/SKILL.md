# 代码编辑

修改代码文件时，严格遵循以下流程。

## 流程

### 1. 读取

修改任何文件之前，**必须先 read_file 读取完整内容**。
- 如果同一轮对话中已经读过，可以跳过。
- 如果不确定文件内容是否变化过，重新读取。

### 2. 分析

阅读代码后，分析：
- 这段代码的作用是什么？
- 我要改的部分在哪个位置（行号）？
- 周围代码的风格是什么？（缩进、命名、注释密度、语言习惯）

### 3. 编辑

- **优先用 edit_file 做精确行编辑**，而不是整个文件重写。
- 匹配现有代码风格——不要突然改缩进风格或命名习惯。
- 每次编辑尽量小而精确。一个大改动拆成多个小编辑。

### 4. 验证

编辑完成后，**立即验证**：
- **语法检查**：如果是 Python，运行 `python -c "import ast; ast.parse(open('file').read())"` 或 `python -m py_compile file`
- **运行测试**：如果有测试，运行 `pytest` 或等效命令
- **回读确认**：如果无法运行，至少 re-read 编辑过的行，确认改动符合预期
- **诚实报告**：如果验证失败，如实告诉用户失败原因和错误输出

### 5. 记录

如果这次编辑解决了某个非显而易见的问题，写入 memory：
- 什么问题？
- 为什么这个解法有效？
- 有没有需要注意的坑？
